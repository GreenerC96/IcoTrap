# Follow the project rules

The rules must be followed.

`rules.md` holds the icosahedron, tile, and wind definitions. Wind generation is in `world-generation.md`.

1. Read `rules.md` and `world-generation.md` before changing the world, tiles, tile types, or wind.
2. Implement only behavior that matches those files.
3. When the user changes a rule, update the file that holds that rule in the same change so it stays accurate.
